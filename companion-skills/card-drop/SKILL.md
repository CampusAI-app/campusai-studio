# /card-drop

Read the studio skill, then "Named styles, one prompt each" in its `lanes/motion.md`, and follow it for `Style-CardDrop`
with the subject given here. The subject is the only input: never ask for a pitch or a structure, and only stop when a
word or number on screen has no source. It is WebGL, so add `--gl=angle` to the render command.
